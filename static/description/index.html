📋 About the Module

Hilatech Export Accounting Reports adds an "Export Excel" button to 12 accounting report wizards from the Base Accounting Kit module, as well as to customer and vendor invoices.

Exports faithfully reproduce the hierarchical formatting of Odoo's PDF reports, including company headers, period, filters, child account indentation, bold totals and monetary formatting. An essential tool for accountants, auditors and controllers who need to rework data in Excel.

✨ Key Features

🎨 Faithful Formatting

  • Reproduces the PDF hierarchy
  • Automatic indentation of child accounts
  • Bold totals and subtotals
  • Localized monetary formatting

🏢 Custom Header

  • Company name and logo
  • Report period (From / To)
  • Applied filters (journals, accounts)
  • Move type (Posted / All)

⚡ Native Integration

  • "Export Excel" button on every wizard
  • Same filters as PDF printing
  • Direct XLSX file download
  • No workflow changes

🔢 Actionable Data

  • Numeric values (not text)
  • Formulas and sorting available in Excel
  • Auto-adjusted column widths
  • Compatible with Excel, LibreOffice, Google Sheets

🌍 Multilingual

  • Headers translated to user language
  • Compatible with translated JSONB fields (Odoo 17+)
  • Localized date formats
  • Multi-company currencies supported

🔒 Safe and Lightweight

  • No modification of Odoo models
  • Clean install and uninstall
  • Single dependency: xlsxwriter
  • Compatible with Odoo Enterprise & Community
